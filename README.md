# meraki-web

Sitio web de Meraki Technology S.A.C. — https://meraki.net.pe

Sitio estático (HTML + CSS) publicado con GitHub Pages desde la rama `main`.

- Ver en local: abrir `index.html`, o ejecutar `python -m http.server` y entrar a http://localhost:8000
- Publicar: `git add . && git commit -m "mensaje" && git push`
- Documentación del proyecto: `D:\CEREBRO\10_Proyectos\MERAKI`
